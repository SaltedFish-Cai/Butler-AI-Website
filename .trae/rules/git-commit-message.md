# Git 提交信息规范

## 提交信息格式

feat/fix/refactor: 简短描述

## 规则

- **必须使用中文**编写提交描述
- 格式：`<类型>: <中文描述>`
- 类型使用英文小写（feat/fix/refactor/docs/chore/style/perf/test）
- 描述简明扼要，不超过 50 字
- 必要时可以附加详细说明（空一行后补充）

## 示例

- feat: 新增用户登录页面
- fix: 修复数据绑定为空时报错的问题
- refactor: 重构表格编辑器交互逻辑
- docs: 补充 API 文档说明
- chore: 更新依赖版本
